# small-step-big-leap — タブレット同意＆デジタルオーナー証アプリ

子どもが初めてのタブレットを受け取る際に、3D演出付きの同意フローと、同意結果を記録するデジタル証明書を表示するWebアプリです。

## 概要

- タブレット起動時に3D宇宙演出(Babylon.js)を表示する
- 利用規約(お約束事項)への同意を、子ども自身の操作で行わせる
- 同意結果・日時をLocalStorageに保存し、以降は直接ダッシュボード(デジタルオーナー証)へ遷移する
- 名前・お約束文言は`config.js`で家庭ごとに変更できる

## 技術構成

| レイヤー | 技術 | 用途 |
|---|---|---|
| 3Dエンジン | Babylon.js | 宇宙演出のレンダリング |
| フレームワーク | Next.js (static export) | ページ遷移制御 |
| 状態管理 | LocalStorage | 同意ステータスの永続化 |
| 設定管理 | config.js | 名前・お約束文言の外部化 |

## 特徴

- Babylon.js・Tailwind CSS・フォント・背景画像をすべて`public/vendor/`に同梱しており、オフライン動作。Wi-Fi未設定の開封直後でも演出がそのまま動作する
- 同意の記録は`localStorage`に保存し、2回目以降はオーナー証の画面へ直接進む。`localStorage`が使えない環境では自動的にメモリ保持へ切り替わる(詳細は`public/runtime.js`を参照)

### 方法2: `public/config.js`を編集して作り直す

リポジトリを取得済みの場合は、`public/config.js`を編集してから、お使いの環境に応じて次を実行すると`standalone/small-step-big-leap.html`が作り直されます。

| 環境 | 操作 |
|---|---|
| Windows | `build_standalone.bat` をダブルクリック |
| macOS | `build_standalone.command` をダブルクリック |
| 共通(コマンド) | `npm run build:standalone` |

こちらはNode.jsが必要です。開発サーバー版(`npm run dev`)やフォルダ配信版も同時に更新されます。

## 起動方法

### A. Windows で起動する

`start_app.bat` をダブルクリックすると、開発サーバーの起動を待ってからブラウザが開きます。

コマンドで実行する場合:

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) にアクセスします。

### B. macOS で起動する

`start_app.command` をダブルクリックすると、開発サーバーの起動を待ってからGoogle Chromeで開きます(Chromeが無い場合は既定のブラウザで開きます)。

初回のみ、ターミナルで実行権限の付与が必要な場合があります。

```bash
chmod +x start_app.command build_standalone.command
```

コマンドで実行する場合はWindowsと同じく`npm install` → `npm run dev`です。

### C. Android / iPad タブレット単体で運用する(単一HTMLファイル版・推奨)

[`standalone/small-step-big-leap.html`](standalone/small-step-big-leap.html) の1ファイルだけをタブレットにコピーし、それを開くだけで動作します。ネット接続もサーバーも不要です。CSS・JavaScript・フォント・画像をすべて1つのHTMLに埋め込んであるため、外部ファイルを参照しません。

> Androidの「ファイル」アプリからHTMLを開くと、Chromeには`file://`ではなく`content://`という「フォルダの概念を持たない」アドレスで渡される。この状態では`<script src="vendor/...">`のような相対パス参照が解決できず、CSSもJavaScriptも読み込まれないまま真っ黒な画面になる。フォルダごとコピーする方法が機種によって動いたり動かなかったりするのはこのため。単一ファイルにすれば相対パスがゼロになり、この問題が原理的に発生しない。

ファイルを再生成する場合は、`public/`以下を編集したあとに次を実行します。

| 環境 | 操作 |
|---|---|
| Windows | `build_standalone.bat` をダブルクリック |
| macOS | `build_standalone.command` をダブルクリック |
| 共通(コマンド) | `npm run build:standalone` |

#### 証明書の保存とリセット

同意した記録は`localStorage`に保存します。ファイルアプリからHTMLを開くと、ブラウザには`content://`というアドレスで渡されることがあり、この形式での保存可否は端末やブラウザのバージョンによって異なります。

- 保存できる場合(Lenovo Idea Tab / Chrome で確認): アプリを閉じても証明書が残り、次回はオーナー証の画面から始まる
- 保存できない場合: 自動的にメモリ保持に切り替わる。演出から証明書の表示までは動作するが、アプリを閉じると消える。

一度同意すると、次に開いたときは演出を飛ばしてオーナー証の画面から始まる。最初からやり直したい場合は、オーナー証の画面を下にスクロールして「もう一度演出を見る」を押すか、URLの末尾に`?reset`を付けて開く。

お子様に渡す前に動作確認で同意した場合は、渡す前に一度リセットしておくと、開封時に演出から始められる。OSがタブを再読み込みした場合も、リセット済みであれば同じく最初のタップ待ち画面から再開する。

`file://`で開いたページの保存データは、Chromeがローカルファイル全体でひとまとめに扱う。そのためファイル名を変えても以前の記録が残る。消す場合は「閲覧履歴」ではなく「Cookie と他のサイトデータ」の削除が必要。
